# 判字细则（rubric）

不给目标字（盲读），不附例图。AI 先读出看到的字，再给每个字打 0/1/2；对不对目标由代码比较。

## 每个字的三档

| 档 | 含义 | 典型情况 |
|---|---|---|
| **2 规范** | 一眼认得，部件、笔画都对，结构正常 | 书法体、艺术字、粗细风格不扣分 |
| **1 有毛病但能接受** | 认得出就是这个字，部件都在、没换错；毛病只在笔画层面 | 断笔、粘连、笔画长短/角度不对、多一个小点或少一个小点但不会变成别的字；部件位置或比例变形但仍可辨认 |
| **0 错** | 不是这个字，或不是字 | 部件换了（雨→兩）；多笔或少笔后变成另一个字或不存在的字；乱码、造字；糊到认不出 |

判不准时：
- 在 1 和 2 之间犹豫 → 给 1；在 0 和 1 之间犹豫 → 给 0，并在 note 里写原因。
- 简繁不同算不同的字：照实读出写的是哪个字（写了"坛"就读"坛"，不替它改成"壇"）。
- 异体字也照实读出，不归并。

## 单字任务

一张图一个字，输出：
```json
{"read": "徕", "grade": 1, "confidence": 0.9, "note": "彳旁变窄"}
```
判对 = `read` 等于目标字 且 `grade ≥ 1`。

## 场景 / 多区域任务

每个字单独打分，按阅读顺序列出（多区域：从左到右，每块招牌一组）。图里多出来的乱码字形也列出来，记作 `□`、grade 0。
```json
{"signs": [[{"c": "老", "g": 2}, {"c": "街", "g": 1}],
           [{"c": "茶", "g": 2}, {"c": "□", "g": 0}]],
 "confidence": 0.85, "note": "第二块招牌末尾多一个乱码字"}
```
代码把读到的字和目标逐字对齐，得到：
- **逐字写对率**：目标里的每个字，读到且 g ≥ 1 才算对（漏字算错）；
- **整句全对**：所有字都对、没有多余字、顺序对。

## 把握分数

`confidence` 0–1，对整张图的判断有多确定。看不清、拿不准的给低分（< 0.8），之后单独拿出来人工看。
